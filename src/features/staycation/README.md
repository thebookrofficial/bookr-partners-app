# Staycation Feature

This directory contains the Staycation service category implementation.

## Structure

- `components/`: Feature-specific UI components.
- `hooks/`: Custom React hooks for staycation logic.
- `screens/`: Navigation screens for staycation workflows.
- `services/`: API and business logic for staycations.
- `types/`: TypeScript definitions.
- `utils/`: Helper functions specific to staycations.
