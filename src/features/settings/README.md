# Settings Feature Module

This module handles application-wide settings, support, and account management actions.

## Core Screens

- **`SettingsScreen`**: A centralized list of links for legal policies, help/support, and account actions (Logout/Delete).

## Key Components

- **`SettingsActionRow`**: A standardized row component used for all settings links, supporting icons, labels, and "danger" states for destructive actions.
